# VocabMaster 单词达人

小学英语背单词 Web 应用：单元选择、拼写/认词练习、错题本、课文例句、打印卡片。

## 在线使用（GitHub Pages）

打开仓库 Pages 地址即可。线上为纯静态托管：

- 学习进度保存在浏览器 `localStorage`
- 每次答题会保存为学习事件；首页的「今日学习报告」和「近 4 周学习追踪」会显示当天与近几周的学习量、学习天数、答对/答错次数及正确率。连接阅读器 Supabase 账号后，这些事件会随学习档案跨设备同步。
- 临时生成 AI 助记需本地服务（见下方）
- 三至五年级上下册有预先编写的单词助记。练词时点击「课本单词助记」；答题后点击「练本单元拼写」，一次记一个词的具体字母线索，再全部收起，看中文写完整单词。页面指出漏写、多写或需要替换的字母，随后重新写。情境故事单独放在「课本词情境阅读」，用于理解用法。以上内容无需 AI 服务。
- 单词助记按词选择拼读、真实构词、可核实的词源或具体联想，帮助连接读音、拼写和词义。例句用来练用法；词组翻译不能单独充当助记。创作故事标作联想，不当作词源解释。
- 阅读助记后，点击「收起线索，试着回忆」：看中文独立拼写，或看英文读出并说出意思，再核对和重试。练习只供自查；认读须跟标准音频核对。
- 六册课本词的拼读、构词和联想已合并为同一份预编资料，学习、闪卡和打印共用；无需再生成另一份 AI 拼读卡。只有未配备专属资料的扩展词保留 AI 补充入口。
- 普通拼写、助记回忆和单元拼写均显示国际音标；课本词优先使用 `phonetics.json` 的预编读音，本地朗读或在线词典不可用时仍可显示。未取得可靠音标的专名会明确提示听标准读音。扩展词可查询在线词典，切换单词时不会被上一词的慢响应覆盖。
- `hello/hi` 与 `a/an` 已拆成独立词条，分别练习和记录进度；旧档案加载时自动迁移，原编号保留历史进度，新拆出的 `hi`、`an` 从未练习开始。重复加载不会重置新增词的进度。正常词组和 `life (pl. lives)` 复数注释保留。

## 本地运行（完整功能）

1. 复制配置：`cp ai_config.example.json ai_config.json`，填入 API Key  
2. 双击 `启动单词.command`，或：

```bash
python3 vocab_server.py 8080
```

3. 浏览器打开 <http://127.0.0.1:8080/vocabulary_app.html>

本地服务可把进度写入 `vocab_data.json`，并代理 AI 助记接口。

## 主要文件

| 文件 | 说明 |
|------|------|
| `vocabulary_app.html` | 主应用 |
| `词库.md` | 词库 |
| `phonetics.json` | 课本词的预编国际音标及来源说明 |
| `mnemonics/grade3.json`、`grade4.json`、`grade5.json` | 三至五年级课本词助记与单元故事 |
| `四上英语课文.md` | 课文原文（中英） |
| `vocab_server.py` | 本地持久化 + AI 代理 |
| `ai_config.example.json` | AI 配置模板（勿提交真实 Key） |

## 助记资料校验

运行 `python3 tests/validate_mnemonics.py` 检查六册词表覆盖、故事目标词和中文回忆线索。

质量标准见 `mnemonics/QUALITY.md`。逐词审核记录单独保存认读、拼写与回忆的判断依据；运行 `python3 tests/validate_mnemonic_audits.py` 检查记录是否完整、是否仍对应当前文本。这些检查不能替代教学质量判断或儿童实际记忆效果观察。

浏览器检查使用 `tests/test_mnemonic_ui.py`：先在另一终端运行 `python3 -m http.server 8766`，再运行该脚本。脚本拦截学习记录接口、使用独立测试档案，并输出单词助记、单元拼写与纠错预览图；测试服务使用静态服务器，避免写入真实学习记录。

运行 `node tests/test_mnemonic_helpers.cjs` 检查闪卡/打印使用预编资料，以及词表中的组合词形接受真实拼写。浏览器检查另外核对学习、闪卡和打印的助记一致，回忆答案隐藏且自查不写学习记录。

运行 `node tests/test_vocab_migration.cjs` 检查独立词条、旧进度迁移和重复导入；运行 `python3 tests/validate_phonetics.py` 检查课本词的音标覆盖与明确缺项。在上述静态测试服务运行时，执行 `python3 tests/test_spelling_ui.py` 检查本地/在线朗读、词典不可用、三个拼写入口的音标，以及切词后的异步响应保护。测试使用隔离档案与模拟接口，不写真实学习记录。

## 从英语阅读器导入生词

在英语阅读器的「我的生词本」点击「传到 VocabMaster」，然后在本应用创建或选择用户并点击「教师确认后导入」。教师须逐项勾选需要导入的词；未勾选的词会保留在待导入列表中。AI 可以提供筛选建议，但不会自动导入任何词。这些词位于独立的「阅读生词本」，只进行“见英选义”，不会进入错题本或要求拼写。

阅读生词本支持两层整理：先按**来源文章**或**导入日期**筛选，再按学习表现分为「生词」「难词」「已掌握」。难词为答错至少两次，或答错次数不少于答对次数的单词；已掌握为闪卡标记“已会”，或答对稳定的单词。筛选条件会随学习档案保存。

阅读词答错后也会进入独立的「阅读错题本」；连续答对 2 次后自动移出，可随时单独复习。

在阅读生词本点击「管理删除」，验证阅读器账号密码后，可跨学习组勾选、全选并批量删除不需要的词；删除的词会在后续导入时被忽略。

跨设备使用时，先在阅读器登录同一 Supabase 账号；本应用会读取该账号同步的生词，并同步全部 VocabMaster 学习档案（各年级/单元进度、错题本和阅读生词本状态）。
