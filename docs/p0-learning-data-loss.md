# 学习记录丢失：P0 根因与修复

## 已证实的同步故障

2026-09-22 的提交 `1f3596d` 把阅读队列游标保存为日期、NUL 字符和词 ID 拼接的字符串。游标随整份学习档案写入 PostgreSQL `jsonb`。PostgreSQL 不允许 JSON 字符串包含 NUL，因而拒绝这次写入。一个阅读游标会阻断所有年级的答题、错题和每日学习记录同步。

生产数据库日志的直接证据：9 月 30 日有 113 条、10 月 1 日有 123 条 `unsupported Unicode escape sequence` 错误，SQLSTATE 为 `22P05`，详情为 `\\u0000 cannot be converted to text`，上下文明确指向 `readingQueueCursor`。只读 SQL 复现得到相同错误。按上海时区的 10 月 1 日统计，Edge 对学习状态接口出现 109 次 POST 400；同接口的其他成功请求不能证明整份学习档案保存成功。

旧客户端只处理写入成功分支。失败没有可靠提示、持久待发送队列、自动重试或逐条确认。登录或连接成功因此被误当成学习档案保存成功。

## 本机记录消失的放大机制

8 月 31 日提交 `2439bb8` 引入强制读取时以云端完整替换本机档案的分支。如果云端仍是旧快照，这条路径能丢弃从未成功上传的本机新记录。现存日志不能证明这次最终清空一定由该操作触发：事发前没有保存请求载荷和档案版本审计。**已证实的是云端长期拒绝写入；最终覆盖触发操作仍未完全证实。**

其他缺陷包括：客户端读取后整份覆盖产生并发竞争；按词累计计数取最大值不能保存并发答题；每日事件曾截断到 5,000 条；缺少独立答题日志和可追溯的旧版本。三下重复单元迁移另有问题，但不能解释所有年级学习记录丢失。

## 三下 60 个错题的来源与纠正

这 60 个词来自 18 份五月到六月导出文件中曾答错词的并集。导出不包含逐次答题事件、错题退出状态或可靠学习时间，且快照之间存在重置和不连续性。恢复程序跳过后来的零计数，并取各词旧计数最大值，错误复活了旧错题。

六月最后一份导出中只有 28 个词有历史错误计数；上述 60 个词中已有 32 个错误计数为零。8 月和 10 月快照的三下计数为零。不能据此把 60 改成 28，也不能猜测用户主动清空了记录。

纠正范围为来源不可靠的 142 个三下词及 3 个音乐词。原始快照与错误恢复结果独立留档；只撤销这批无逐次答题证据的恢复计数，保留真实答题事件和其他有依据的恢复内容。管理员纠正必须锁定最新档案、归档旧版本并更新基线版本；不能上传一份陈旧的全量文件覆盖用户新答题。

## 保存机制修复

- 阅读游标改成结构化字段，兼容旧游标；发送前拒绝其他 NUL 字符。
- 每次答题在反馈成功前写入按账号隔离的本机待同步队列。存储失败明确提示；队列不依赖可替换的界面快照。
- 云端同一事务保存不可变答题事件并更新累计状态，用事件 ID 去重。重复请求不能重复计数，并发答题串行合并。
- 本机只有收到确认且云端返回历史包含该事件，才能移除待发送记录。断网、接口报错、重载和请求过程中新增答题均保留待发送事件。
- 云端累计计数为权威投影；旧网页直接写入也受数据库保护，不能用旧快照删除历史或重新带入旧计数。
- 管理员纠正更换基线版本。客户端遇到版本冲突先读取当前档案，再只重放未确认的真实答题。
- 保存档案版本及独立答题日志，不再截断每日答题历史。完整导出包含档案和待同步队列。

## 验证与限制

验证覆盖：旧 NUL 游标、存储空间失败、接口失败重试、重复提交、缺失回执、请求中新增答题、账号切换、基线纠正、超过 5,000 条历史、旧客户端覆盖、事务并发以及账号访问隔离。发布结果和恢复数量以实际执行记录为准。

2026-10-03 已部署数据库迁移 `p0_durable_learning_journal_and_snapshot_guard`，并完成 145 个词的审计纠正。纠正后云端快照和独立日志均为 518 条真实事件，今天新增的 `remember` 答错事件保留。三下和音乐的错误恢复计数已隔离，原始证据和纠正前完整档案保留。

本地 PostgreSQL 17 的事务回归和实际双连接并发回归通过。用完整 4,192 词／518 事件档案测试：初始化约 0.21 秒，普通同步约 0.26 秒；两次并发答题均保存且各计一次。客户端测试直接运行实际保存与同步效果函数，验证收到确认后停止重复发送，以及请求期间新增单词、选择和答题保留。跨标签页待发送记录按事件独立保存，确认只移除指定事件。

累计次数只能恢复累计状态，不能推造不存在的每日答题事件。未找到的逐日记录仍需保留为未知，不能把“当前数据库没有”表述为“从未学习”。本次不使用时间机器。
