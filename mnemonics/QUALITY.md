# 助记质量标准

主要目标：孩子只看到中文意思时，能独立写出正确的字母顺序。认读帮助建立声音与字母的联系；想到词义或点开答案不能算会拼写。

## 逐词验收

1. **认读线索**：指出这个词的实际声音与字母对应、重音或不规则读法。音标供核对，孩子先听标准读音；不把会读音标设为使用前提。
2. **拼写线索**：指出有用的字母组合、熟悉组成词、双写、不发音字母、易混或例外。声音不能唯一确定的拼写要明说，不能声称听音就一定写对。
3. **回忆动作**：先学具体字母线索，再收起整段线索和英文答案，写完整单词。检查漏字、多字和错字，收起答案重新写；稍后再写一次。猜一个词、回答“几个字母”或点开答案均不替代完整拼写。
4. **负担**：只保留帮助取回词义、声音或字形的信息。给东西贴英文牌、给箱子/路线起字母名，本身没有形成新的取回线索。
5. **准确**：创作字形联想与真实词源分开。词根或组成词不熟悉时，补充所需读音/字形，不能让孩子靠另一个陌生词来记这个词。

不是每个词都适合故事。规则词优先声形对应；熟悉的复合词优先组成；困难字形可以用直接图像或有声音/字形桥梁的联想。没有合适故事时使用明确的拼读和拼写提示。

## 多维助记的第一性原则

先确定要取回的内容，再选线索。孩子要建立的是词义、声音、字母顺序及用法之间的联系；“维度多”“卡片漂亮”都不是学习成果。每个新增线索必须说明帮助取回什么，并尽量连到孩子已经理解的概念。

- **视觉**：实际展示动作、空间关系、物件变化或关键字形。sorry 的两个人分别对应两个 r，dessert 的两份甜点对应两个 s，would 中保留不发音的 l。肉搓成球的图帮助连接 meatball 的意义。图像能帮助认义，不一定能唯一确定拼写；没有字形桥的图不声称能够直接教会拼写。图示和创作联想不作为真实词源。
- **语义**：用分类、反义、部分与整体、时间顺序、指代或易混区别建立联系。不能把中文翻译再说一次就算增加维度；也不能只列一串更陌生的英文词。
- **情境**：明确谁在什么情况下用这个词，给自然例句，并用不同情境的问题要求主动取回。核对前隐藏例句和英文答案。句子可以有多种正确表达，页面只供参考，不自动声称已经会用。
- **构词**：区分词缀（affix）、复合词（compound）、形式变化（inflection）和词组（phrase）。基本词或不透明词使用 none；拼读分段不是词根。remember 不解释为 re＋member，uncle 不解释为否定前缀 un-，welcome 不把熟词拼写联想当作现代透明构词。变化形式要讲清双写、去 e、y 变 i 等实际规则，不能只把组成块机械连起来。
- **负担与检索**：学习页面一次只呈现一种线索；孩子选有用的一条后收起再试。拼写回忆卸载图像、字母标记、例句与构词；情境回忆只保留不含英文答案的新问题。即时照抄不等于稍后的独立回忆。

图标入口保留文字，帮助识别线索类型。词卡按内容选择图形：空间关系直接画位置；透明组合用图与组成词对应；形式变化显示变化前后并标记关键字母；多义词突出本课义项。只有真实组合或变化才使用加号、等号、箭头，不给所有图标套同一模板。图旁短标签解释图意，不能替代遮住后的读、写或用词。

具体图解另行统计，普通图标及画面描述不计入覆盖。对照图必须明确两种对象、属性或义项的实际区别；数量图画出十格分组，序数图标出位置；身体与植物图指认完整对象中的部位；亲属图显示亲子连线及不同家庭支系，不能仅凭男女人物猜亲属；钟面按分钟推动时针；字形变化只标实际变化的位置。过程箭头表示先后，不能把原料、环境或付款误说成物体自己发生变形。

指代图同时控制远近与单复数；人物关系图区分做事者、动作对象与所有者，反身关系明确是同一个人。方向图标出起点和终点，from 与 to 高亮不同端点，返回须显示先带走再带回；来源图不声称说话时正在移动。频率示例中 always 是全发生、never 是零发生，often 没有固定百分比。only 表示限定范围而非永远只有一个；quite a few 表示不少而非固定多数；more than 必须同时画出比较基准和严格大于关系。

时间图以现在、约定时刻或具体事件为参照，ago 连时间长度，before/after 连事件先后，from then on 标持续范围。类别图画成员归属，避免把类别说成词根相加或所有状态同时发生。结构图应显示物体真正相关的特征、作用或路径；整体与部分保持同一个整体的边界。多义词先核对本课例句，例如 square 在广场义项中画开阔公共场地，不能用正方形冒充。

每条审核记录的 `graphicReview` 标明是否有具体图解、主要取回目标及设计理由。`meaning` 图用于理解或辨义，不能算作拼写掌握；`spelling` 或 `both` 必须有真实字形线索。覆盖报告见 [GRAPHIC_COVERAGE.md](GRAPHIC_COVERAGE.md)，可用 `python3 tests/validate_mnemonic_dimensions.py --report` 根据实际内容重新生成。尚未图解的词保留判断理由，不能通过换一个图标改记为完成。

2026-10-02 新增 `dimensions` 资料与 `dimensionsSha256`、`dimensionsRationale` 记录。原有声音与字母提示保留，学习、单元拼写、闪卡和打印读取同一份资料。结构校验和回归检查能检查覆盖、已知错误构词、版本一致及答案隐藏；内容理由是设计判断，不能替代儿童实际学习效果观察。

设计依据：构词教学的研究综述支持把真实形态知识与其他读写教学结合（[Bowers、Kirby 与 Deacon，2010](https://journals.sagepub.com/doi/10.3102/0034654309359353)）；主动检索的实验支持先尝试取回再核对（[Karpicke 与 Blunt，2011](https://pubmed.ncbi.nlm.nih.gov/21252317/)）。将这些机制应用到本词库是设计推断，不代表这些研究已经验证本页面或中文母语儿童的每条助记。

## 故事验收

情境阅读连接词义与事件顺序，目标词须符合情境、意义正确。英文使用完整、自然的句子或合适的短语，避免把英语动词硬插进中文语法。

要作为拼写助记，情节必须把具体字母或字母组合变成可回忆的线索，例如 sorry 的两个 r、would 的静音 l。必须能回答“这个画面帮助记住哪个字母、什么顺序、为什么能取回”。单纯把目标词放进故事、再根据情节猜词，不能通过拼写助记验收。

故事覆盖目标词只能证明完整性，不能证明孩子学会拼写。每词的声形助记和独立回忆练习仍需通过上述验收。

## 审核证据与界限

2026-09-30 本轮逐条复核：三年级 301 条、四年级 260 条、五年级 327 条，共 888 条；36 个单元故事也逐幕复核。修订包括弱读和不发音字母、真实构词与拼写分段的区别、教材义项，以及不成立的字母标签联想。学习、闪卡和打印共用同一份预编资料。

用户随后指出故事任务只让孩子猜词，未检验拼写，因此此前的故事审核不能作为拼写教学通过的证据。本次把猜词列表移出学习入口，改为逐词“看具体字母线索 → 全部收起 → 写完整词 → 字母纠错 → 重写”。四上 Unit 3 第一组六词新增独立 `spellingCue` 和关键字母标记；其余词沿用已有单词线索，未宣称所有故事已重新改成字母助记故事。

`audit-grade3.json`、`audit-grade4.json`、`audit-grade5.json` 逐词记录认读线索、拼写线索、回忆任务及判断理由；`hintSha256` 将记录绑定到审核时的文本。改动文本后必须复审。

自动检查验证覆盖、审核记录完整性和文本版本一致性；它不能判断联想是否好用，也不能证明儿童记忆效果。内容审核负责判断线索是否成立，页面测试负责确认答案确实隐藏、可核对、可再试。实际效果应看孩子稍后不看提示能否认读和拼写，不能用读过卡片或立即照抄算掌握。

方法依据：[拼写记忆中的声音与字母联系（Ehri）](https://doi.org/10.1080/10888438.2013.819356)、[字母与声音对应的教学综述（NICHD）](https://www.nichd.nih.gov/publications/pubs/nrp/findings)、[声音桥与互动图像的关键词助记研究](https://files.eric.ed.gov/fulltext/ED096816.pdf)、[检索练习研究](https://doi.org/10.1126/science.1152408)。这些支持设计机制，不代表本词库已经过儿童效果实验。
